# 实验五执行清单

截至 2026-11-14。本清单记录实际实现与验收，不将配置文件或模拟测试等同于真实部署和训练。

## 已完成

- [x] 使用用户提供的 300 行 CSV，记录来源哈希与清洗方法。
- [x] 生成 100 条训练候选、10 条验证候选、10 条测试候选，植物 ID 与相同文本不跨划分。
- [x] 明确标签为来源字段弱监督，记录缺少的类别与评估边界。
- [x] 新增植物文本分类 API；10 条独立保留样本零样本评估，与来源字段标签一致率 10/10，平均 797.73 ms。
- [x] LangChain `create_agent` 及四个受限工具：检索、详情、图像识别、文本分类。
- [x] JSON Agent 接口和 NDJSON 流式接口，包含用户、回答、工具调用结果。
- [x] 工具最多重试 3 次，工具不存在、无权限与输入无效有对应错误处理。
- [x] 本机并发/等待容量限制；队列代码包含 Redis/Celery 优先级和超时配置。
- [x] 首页现有问答区域接入 Agent，可上传植物图片、查看实时工具状态和结果。
- [x] 账号会话保存工具记录，刷新恢复、多轮续聊和账号关联通过验证。
- [x] 跨账号图片访问被拒绝，任意文件路径不允许作为工具图片输入。
- [x] 10 轮真实 Agent 工具评估，10/10 选中预期工具，平均 2699.10 ms；本次样本满足准确率 ≥90% 与平均延迟 ≤5 秒目标。
- [x] 前端构建、34 项前端测试、18 项 Agent/队列/数据测试通过，既有公开内容与数据库相关回归通过复测。
