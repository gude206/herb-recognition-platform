# 数据采集与预处理

## 一 实验目的

以 TCMP-300 中药用植物图像及其类别元数据为对象，完成公开数据获取与来源记录、文件格式检查、标签一致性核验、图像预处理与增强、数据集划分和文档化。通过核对原始数据、处理参数和输出清单，理解完整性、一致性及代表性对数据集可用性的影响，为后续实验提供可追溯的数据输入。

本实验采用两类相关数据：按植物类别组织的非结构化图像，以及记录编号、学名、科名和中文名称的结构化 CSV。扩展植物描述资料作为辅助元数据，用于说明名称核对、缺失资料处理和来源追踪。

## 二 实验环境

实验项目在 Windows 环境中组织，Notebook 记录的内核为 SXLWFX、Python 3.10.20，图像处理代码使用 Pillow、PyTorch 和 torchvision，图像效果通过 Jupyter Notebook 与 IPython 展示，表格及划分文件采用 UTF-8 编码 CSV，划分参数使用 JSON 保存。数据核验使用 Python 的 csv、json、pathlib 和 hashlib 等模块。具体硬件、实验日期和软件版本待封面与环境信息确认后填写。

## 三 实验内容与步骤

### 1 需求分析

按照实验任务书，数据处理分为多源数据获取、数据清洗与增强、数据集建设三个阶段。对于本实验，图像应与标签一一对应，类别编号需稳定，随机增强应保留植物识别所需的主体特征，数据集划分应可复现且清单之间不存在路径重叠。原始文件、规范信息和待核实记录分别保存，以便追踪处理过程。

质量评价采用实际检查结果，包括文件数量与格式分布、核心标签缺失率、重复记录数、类别覆盖率及划分清单交集。不通过模型训练或分类准确率评价本次数据处理。

### 2 设计思路

处理链路为：定位作者公开数据源，记录下载版本和校验值，解压并按类别核对数量，检查 CSV 核心字段，保留原始名称并关联规范字段，按受支持的格式建立可用图像清单，构造固定与随机图像变换，生成固定分层划分清单，最后整理数据集说明和数据卡片。

可用图像通过读取时变换转换为 RGB 图像、统一空间尺寸并生成归一化张量。随机增强只应用于训练分区的数据输入，验证和测试分区采用确定性变换。此处仅构建数据输入规则，不进行模型训练。

### 3 代码实现

#### 1.1 多源数据获取

图像与基础标签来源为 TCMP-300 作者数据集，数据引用为 https://doi.org/10.6084/m9.figshare.29432726，下载仓库为 https://huggingface.co/datasets/anzhulin/tcmp-300。现有核验记录将仓库版本固定为 7613f038f48e3ecc84076913a2f3bcd52599b0f2。

下载文件 tcmp-300-release.tar.gz 的记录大小为 12,820,492,346 字节，SHA-256 为 f3d32fb003cccf817c735aaa0978a5381058aa77ec5d410a818b720b048d5739。核验并解压后，压缩包因节省存储空间而删除；该校验值引用下载时的记录。

解压目录包含 train 与 val 两个分区，各有 300 个类别目录。文件总数为 52,172，其中 train 为 36,381 个，val 为 15,791 个。扩展名包括 JPG、JPEG、PNG、BMP、WEBP 和 GIF。基础标签 CSV 为 300 行、4 列，字段分别为 No、Latin Name、Family、Chinese Name。类别目录的三位数字前缀用于与 No 建立对应关系。

结构化数据读取与检查示例：

```python
import csv
from pathlib import Path

csv_path = Path("data/author_tcmp_300/tcmp-info-20250329.original.csv")
with csv_path.open(encoding="utf-8-sig", newline="") as file:
    rows = list(csv.DictReader(file))
assert len(rows) == 300
assert len({row["No"] for row in rows}) == 300
required = ["No", "Latin Name", "Family", "Chinese Name"]
missing = {key: sum(not row[key].strip() for row in rows)
           for key in required}
```

植物资料补充保留来源名称、链接、检索日期及字段证据，不把外部资料自动替换为原始类别标签。任务书列出的传感器、多模态合成和生成式数据为选做内容，本次资料中未作为独立数据采集项目实施。

#### 1.2 数据清洗与增强

基础标签表的四个核心字段均无空值，整行重复数为 0，No 与中文名称均有 300 个唯一值，因此不对其执行没有依据的缺失填充或重复行删除。学名仅有 299 个唯一值，第 51 类“地肤”与第 141 类“老鹳草”的原始学名同为 Geranium wilfordii Maxim.。该问题属于身份信息冲突，不能仅凭学名相同合并两个类别。现有数据保留两类及原始字段，对第 51 类保留冲突状态和候选名称，等待进一步核实。

对于补充描述，区分“无可靠资料”与“不适用”。无来源支持的药性、毒性及使用注意保持缺失；不以“无毒”或零值替代未查到的数据。规范字段与原始字段并列保存，字段来源单独记录。当前扩展表保持原始四列完全一致，并增加稳定植物 ID tcmp-001 至 tcmp-300。

图像格式检查发现 83 个 GIF。当前 ImageFolder 使用的受支持图像为 52,089 张，其中 train 为 36,324 张，原始 val 为 15,765 张。GIF 未纳入该加载清单，原文件仍保留，因此此处理属于加载范围筛选，不是删除 83 张损坏图像。现有代码对部分截断 JPEG 设置了 Pillow 的容错读取选项，但没有全量损坏图像剔除数量的审计结果。

固定预处理采用短边缩放至 256、中心裁剪至 224×224、转换为张量并归一化。ToTensor 将像素映射至 0—1；Normalize 使用均值 [0.485, 0.456, 0.406]、标准差 [0.229, 0.224, 0.225]，因此归一化后的值不再限定于 0—1。

```python
from torchvision import transforms

fixed_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize([0.485, 0.456, 0.406],
                         [0.229, 0.224, 0.225]),
])
```

随机增强依次使用随机裁剪、水平翻转、垂直翻转、随机旋转和颜色扰动。随机裁剪输出 224×224，面积比例 0.8—1.0，宽高比 0.9—1.1；两种翻转概率均为 0.5；旋转范围为 ±15°；亮度与对比度系数范围为 0.7—1.3，饱和度系数为 0.8—1.2，色相偏移为 ±0.05。

```python
from torchvision import transforms
from torchvision.transforms import InterpolationMode

augmentation = transforms.Compose([
    transforms.RandomResizedCrop(
        224, scale=(0.8, 1.0), ratio=(0.9, 1.1),
        interpolation=InterpolationMode.BILINEAR),
    transforms.RandomHorizontalFlip(p=0.5),
    transforms.RandomVerticalFlip(p=0.5),
    transforms.RandomRotation(15,
        interpolation=InterpolationMode.BILINEAR),
    transforms.ColorJitter(brightness=0.3, contrast=0.3,
                           saturation=0.2, hue=0.05),
])
```

augmentation_preview.ipynb 读取一张婆婆纳类别的图片，展示原图、固定预处理、光度变化、几何变化和四次组合增强。组合预览固定随机种子 2026，输出 augmentation_preview_ZQ.png。该文件是可视化预览，不代表整个数据集已离线扩充或转换为 PNG。

Notebook 的单项示例还使用了亮度、对比度及饱和度系数 0.6、0.8、1.0、1.2，色相偏移 ±0.1、±0.05，以及 +20° 旋转。这些单项演示与组合流水线的参数范围存在差异；报告中的正式增强参数以上述组合变换为准。

#### 1.3 数据集建设

类别目录采用三位数字前缀，ImageFolder 根据目录生成 0—299 的整数编码。训练与原始验证目录必须具有完全相同的类别列表。CSV 清单使用 relative_path 和 class_name 两列，路径采用相对于数据根目录的正斜杠形式，降低换机后绝对路径失效的问题。

训练分区保持作者划分。对原始验证目录的 15,765 张受支持图像按类别分层，使用固定种子 20260927，将约 30% 作为测试分区，其余作为新的验证分区。每类测试数量至少为 1，同时保留至少 1 张验证图片。代码核心为：

```python
import random

rng = random.Random(20260927)
validation, test = [], []
for class_index, class_name in enumerate(source.classes):
    paths = sorted(by_class[class_index])
    rng.shuffle(paths)
    count = min(len(paths) - 1,
                max(1, round(len(paths) * 0.30)))
    test.extend((path, class_name) for path in paths[:count])
    validation.extend((path, class_name) for path in paths[count:])
```

最终形成训练 36,324 张、验证 11,030 张、测试 4,735 张，总计 52,089 张。每个分区均覆盖 300 类。这里的 70∶30 指原始验证目录内部的新验证与测试划分；全部图像的比例约为 69.73%∶21.18%∶9.09%。任务书以结构化数据为例给出 8∶1∶1，本项目当前划分与该示例不同，应按实际记录说明。

数据加载使用 ImageFolder 表示类别目录，以 Subset 应用验证清单，并通过 DataLoader 按批读取。既有校验逻辑检查清单列名、路径重复、未知路径、类别匹配及验证/测试交集。新的文件内容若与已保存清单不同，划分程序拒绝直接覆盖，以防随机划分被意外更改。

### 4 测试优化

对现有 val.csv 和 test.csv 执行只读核对，验证两份清单分别为 11,030 与 4,735 行、各含 300 类，内部均无重复路径，清单交集为 0，路径中的类别目录与 class_name 一致。以现有清单的合并集合在内存中重建分层划分，所得分配与固定清单一致。

不重复存储增强后的全量图片，采用读取时随机变换，避免大量派生文件占用磁盘。验证和测试使用固定变换，以使后续评估输入保持一致。当前路径互斥只证明清单路径不重复，不等同于图像内容完全不存在同源或重复样本；后续可补充内容哈希、感知哈希与人工质量检查。

## 四 实验关键技术与难点

第一，区分磁盘文件数量与可用图像数量。原始目录含 GIF，加载器计数不能直接与所有文件计数混用。通过扩展名统计与明确加载范围，解释 52,172 与 52,089 两种数量口径。

第二，处理类别名称冲突。相同学名不必然表示类别重复；发生中文名、学名和科名冲突时，应保留原始类别编号、标注冲突并记录证据，避免错误合并。

第三，控制随机增强的语义变化。随机裁剪可能切掉花叶，旋转可能引入黑色边缘，色相扰动可能改变具有识别意义的花色。采用较小变换范围并检查预览，仍需扩大样本检查后才能确认各类别适用性。

第四，确保划分可复现。先对类别内路径排序，再用固定种子打乱，保存清单、参数和覆盖检查结果，避免仅记录比例而无法追溯具体样本归属。

### 4 数据集构建与质量评价

| 分区 | 图像数 | 类别数 | 每类图像数量 |

完整性方面，300 类核心标签齐全，新验证和测试清单完整覆盖原始验证可用图片。一致性方面，目录标签与清单标签一致，稳定 ID 唯一，验证和测试路径互斥。代表性方面，各分区保留全部 300 类，但类别样本数并不均衡，也没有按图片来源或拍摄主体分组验证。时效性方面，来源仓库使用固定版本，补充资料记录检索日期，实际知识更新仍依赖后续复核。

原始图像保留混合格式，当前没有全量离线 PNG 转换、逐图 EXIF 清理、模糊筛选、内容去重或隐私审查完成的记录。因此不能把已完成的数量核验和路径检查扩展为全面图像质量审核通过。

## 六 实验总结与展望

本实验围绕植物图像与类别元数据，建立来源核验、数量及格式检查、标签冲突记录、图像变换、固定分层划分和文档化流程。处理后的可用集合为 52,089 张、300 类，新验证和测试清单覆盖原始验证图片且路径互斥，为后续实验提供了明确的数据边界。

数据质量处理需要保留不确定信息。对于名称冲突和缺失植物知识，不应无依据填充；对于随机增强，参数可执行并不意味着语义一定保持。后续可在独立输出目录补充统一 PNG 文件、EXIF 清理、内容哈希去重、模糊检查和多类别增强审查，并根据课程要求决定是否建立 8∶1∶1 的独立划分。模型训练及其评价由后续实验完成。
