# 实验四：中草药图片识别服务与网页交互

日期：2026-11-05。

本次目的：将实验三已有的 INT8 模型接入现有网站，完成图片输入、模型推理、结果展示，并检查功能与展示延迟。沿用真实 TCMP-300 图片和植物资料；保留图鉴、知识问答。按项目范围不开展文本分类、图文匹配。

## 实现

默认使用 `TCMP-300/experiment3/runs/frozen/Q.pt`，在 CPU 上执行。模型对应实验二第19轮权重，类别顺序沿用其300类映射。预处理保持 Resize(256)、CenterCrop(224)、RGB 转换与原归一化参数，保留 EXIF 方向处理及上传限制。不重新训练、校准或导出模型。

```mermaid
flowchart LR
  A[网页上传图片] --> B[FastAPI 校验与预处理]
  B --> C[实验三 INT8 模型]
```

识别和问答成功响应采用 `{code,result,msg}`，参数与已处理的业务错误响应采用 `{code,result:null,msg}`；图鉴、健康状态及示例列表保留原有直接 JSON 格式，图片接口仍返回图片文件。页面显示当前模型名称、模型推理耗时及页面展示耗时，不将原模型的测试集准确率附在 INT8 结果中。

## 本次功能检查

真实图片上传后能够显示模型名称、Top-5 类别及置信度，关联图鉴可以打开详情。选择非图片文件时，页面显示“请选择 JPG、PNG 或 WEBP 图片”。

接口测试比较了同一张真实测试图片通过 HTTP 返回的前五个类别与概率，以及直接加载 Q 模型推理的结果，类别一致、概率在小数点后六位一致。上传限制、错误返回、本地 CORS 和问答接口相关测试通过；问答测试使用已有的模拟上游响应，没有新增付费调用。前端现有测试及生产构建通过。

页面在应用内浏览器中测试。浏览器视口宽度设为390、1024、1440像素时，结果区可见，页面内容宽度不超过可用宽度。此检查只覆盖这些尺寸下的布局，不代表真实手机或其他浏览器已完成测试。

## 接口与调用

| 方法与路径 | 输入 | 主要返回 |
|---|---|---|
| GET `/api/v1/health` | 无 | `status`、`model` |
| POST `/api/v1/predict` | multipart字段`file`，单张JPG/PNG/WEBP，最多10MiB | `result.prediction`、`top_k`、`model`、`timing_ms` |
| POST `/api/v1/chat` | JSON：`message`，可选`herb_id`及`history` | `result.answer`、`references`、`model` |
| GET `/api/v1/herbs` | 可选`q/family/genus/region/effect/property/part/sort/page/page_size/recent_ids` | `total/collectionTotal/page/pageSize/items` |
| GET `/api/v1/herbs/filters` | 无 | 科、属、地区及药材筛选选项 |
| GET `/api/v1/herbs/{id}` | 植物ID，如`tcmp-001` | 植物资料、药材记录、来源和审核状态 |
| GET `/api/v1/herbs/{id}/reference-image` | 植物ID | 图片文件 |
| GET `/api/v1/recognition/samples` | 无 | 真实训练集示例的名称、ID和图片地址 |
| GET `/api/v1/recognition/samples/{id}/image` | 示例ID | 图片文件 |

在项目根目录使用本次第一张测试图片调用：

```powershell
curl.exe -F "file=@TCMP-300/data/author_tcmp_300/images/tcmp-300/val/001.Veronica persica Poir/37aa5827aaaed462caa70667cb425c96.jpg" http://127.0.0.1:8000/api/v1/predict
```

`result.prediction` 包含 `herb_id/name/latin_name/confidence` 及审核信息；`top_k`为按概率降序排列的5个候选。`model`说明实际模型、设备和类别数。`timing_ms`中的`preprocess/inference/total/api`分别为预处理、模型前向、图片处理总耗时、路由处理耗时，单位ms。路由耗时不包括进入路由前的multipart解析及网络传输。页面展示耗时由前端单独计时。

主要错误：400为空或无效图片，404为不存在的条目或路径，413为上传大小或图片尺寸超限，415为不支持的图片格式，422为参数错误，500为识别内部错误。问答另有429限流、502上游请求失败、503未配置或配置错误、504上游超时。详细参数见运行中的 `/docs`。

## 运行与本轮范围

启动仍使用根目录 `start-platform.ps1`，停止使用 `stop-platform.ps1`。网页为 `http://127.0.0.1:5173`，接口说明为 `http://127.0.0.1:8000/docs`。如需使用原模型，在启动前设置 `$env:TCMP_MODEL="original"`；清除该变量后恢复默认 INT8 模型。

本轮维持同步单图请求，没有新增 Celery/Redis 分布式任务、任务轮询或容器部署。单图延迟结果支持当前交互方式，但不替代任务书中分布式任务协调的要求。Firefox、Safari及独立Chrome未实测，三浏览器测试要求尚未完成。小组成员姓名和实际分工需由小组提供，本记录不代填。
